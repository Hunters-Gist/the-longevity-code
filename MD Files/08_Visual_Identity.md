# The Sila Code Visual Identity

## 1. Visual Identity Objective

The Sila Code visual identity must make the brand feel premium, serious, intelligent, clinical, aspirational, and powerful.

The brand should not look like a generic wellness company.

It should not look like a cheap supplement store, a soft yoga retreat brand, a fitness influencer brand, or a dodgy peptide shop.

The visual identity should communicate:

- Trust
- Strength
- Precision
- Luxury
- Science
- Discipline
- Longevity
- Calm authority
- High standards
- Personal transformation
- Modern self-optimisation

The visual system should feel like:

**Luxury pharmaceutical branding meets neuroscience, longevity, and high-performance lifestyle design.**

## 2. Core Visual Direction

The core visual direction should be:

**Dark clinical luxury.**

This means:

- Dark backgrounds
- Clean typography
- Premium spacing
- Minimal interfaces
- Restrained colour
- Strong contrast
- Scientific details
- Editorial layout
- Luxury-level restraint
- No visual clutter
- No cheap effects
- No generic wellness imagery

The design should feel expensive without looking flashy.

## 3. Visual Keywords

The Sila Code should visually feel:

- Premium
- Controlled
- Minimal
- Scientific
- Sharp

## 4. Visual Identity Statement

The Sila Code uses a dark clinical-luxury identity built around black, deep navy, bone white, muted gold, steel grey, and restrained scientific details to create a premium wellness brand that feels intelligent, powerful, responsible, and future-focused.

## 5. What The Brand Should Look Like

The Sila Code should look like:

- A premium longevity platform
- A luxury wellness journal
- A modern pharmaceutical brand
- A neuroscience-inspired lifestyle system
- A high-performance retreat brand
- A premium self-optimisation ecosystem
- A serious health and lifestyle company

The Sila Code should not look like:

- A spiritual healing page

- A generic medical clinic

## 9. Colour Usage Rules

### Backgrounds

Use:

- `#050507`
- `#0A0A0F`
- `#101C2E`
- `#111318`
- `#171A1F`

Backgrounds should feel dark, layered, and premium.

Avoid pure flat black everywhere. Use subtle layers to create depth.

### Text

Use:

- Bone white for headings
- Ash grey for supporting text
- Steel grey for labels, metadata, and captions

Avoid pure white overload. Bone white feels more premium and less harsh.

### Accents

Use muted gold sparingly.

Gold should appear in:

- Small lines
- Button borders
- Icons
- Section labels
- Premium highlights
- Dividers
- Subtle logo details

Do not flood the site with gold. Too much gold looks cheap fast.

### Science Highlights

Use icy blue or cyan-grey sparingly for:

- Data visuals
- Assessment scores
- Scientific diagram elements
- Hover highlights
- Small UI details

## 14. Font Pairing Options

Recommended font pairing styles:

| Pairing Type      | Heading              | Body               |
| ----------------- | -------------------- | ------------------ |
| Premium editorial | Canela-style serif   | Inter-style sans   |
| Clinical luxury   | Neue Haas style sans | Inter or Satoshi   |
| Pharmaceutical    | High-contrast serif  | Clean grotesk sans |
| Modern premium    | Playfair-style serif | Satoshi or Geist   |
| Minimal science   | Space Grotesk        | Inter              |
| Luxury wellness   | Cormorant Garamond   | Manrope            |

Good practical web font combination:

* Headings: `Cormorant Garamond`, `Playfair Display`, or `Libre Baskerville`
* Body: `Inter`, `Satoshi`, `Manrope`, or `Geist`

Best build recommendation:

* Headings: `Cormorant Garamond`
* Body: `Inter`

This gives the site a premium editorial feel without becoming unreadable.

## 46. Visual Identity Risks

| Risk                        | Why It Hurts                | Fix                                      |
| --------------------------- | --------------------------- | ---------------------------------------- |
| Too much gold               | Looks cheap and fake luxury | Use gold sparingly                       |
| Too dark with poor contrast | Hard to read                | Use bone white and proper spacing        |
| Too clinical                | Loses emotion               | Add human imagery and retreat visuals    |
| Too masculine               | Narrows audience too much   | Keep elegance and warmth in imagery      |
| Too generic wellness        | Weak positioning            | Use dark clinical luxury and sharp copy  |
| Too product-heavy           | Looks like supplement store | Lead with method and education           |
| Too much AI imagery         | Can feel fake               | Use real photography as soon as possible |
| Too many fonts              | Looks amateur               | Use one heading and one body font        |
| Too much animation          | Feels gimmicky              | Keep motion subtle                       |
